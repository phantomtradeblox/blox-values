ABOUT BLOX VALUES

Learn more about Blox Values and how the website works.

What is Blox Values?

Blox Values is a community-made website designed to help players check item values and make better trades.

Fruit Values

The Values page allows you to check the current values of fruits and other items available on the website.

Trade Calculator

The Trade Calculator lets you select items from both sides of a trade and compare their total values.

Value Formatting

Large values are automatically shortened using K for thousands, M for millions, and B for billions.
